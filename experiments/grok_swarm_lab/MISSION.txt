- Report sufficiency: for a declared carrier X, report map p, and target query q, a decoder on p(X) exists exactly when q is constant on each realized report fiber. A colliding pair has p(x) = p(y) and q(x) != q(y).
- Unknown coverage: no collision in an observed sample establishes sufficiency only on that sample. A new report or an enlarged carrier requires an explicit coverage decision. A unique execution ID or content hash is useful provenance but is not, by itself, an operational solution to semantic sufficiency on future inputs.
- Evaluator defect: Delta_E = E_global - product(E_local_i) is a comparison of evaluations. Compute it only when a justified global evaluation exists. Zero defect includes joint rejection; report both local and global verdicts before calling a result Local Green, Global Green.
- A collision versus a failed run: a collision refutes report sufficiency. It does not identify which of the two histories occurred or prove that the current task failed.
- Witness composition: boundary identities, baseline, signed differences, semantic versions, representation transport, and outstanding obligations must be retained and checked.
- Endpoint versus every-prefix: an intermediate excursion can be allowed by a terminal query and forbidden by an every-prefix query. State whether an observation is intermediate or terminal. Do not silently substitute one proposition for the other.
- State drift versus consumption: signed changes can cancel; already spent tokens, money, or tool calls do not become unspent because a later state decreases. Track these as separate quantities.
- Repair mathematics: if you use cochains, define the carrier, edge meanings/orientations, D0, and any D1. Check D1 D0 = 0. Distinguish exactness, closure failure, and closed nonexactness. A numeric repair of an encoded cochain needs an application interpretation before it becomes a valid repair of a task.
- Transport: forward commutation transports repairs. It does not automatically preserve nonrepairability. A chain retraction is one sufficient route to reflection, not a necessary condition for every task-specific migration.
- Authorization: a certificate, digest, role name, or successful replay does not authenticate its producer or authorize an external action.

StreamingAuditMonitor.merge calls self.step(w) for each downstream witness without forwarding the downstream global_evaluator_sample or step_cost. The source monitor can report an NGD obstruction while the merged monitor reports composition verified. The source's cost is also omitted from the merged cost.
Minimal reproduction at the reviewed pin:
```
from lggr import BudgetPolicy, StateRef, make_witness
from lggr.streaming import StreamingAuditMonitor

p = BudgetPolicy(query_scope="every_prefix")
s0, s1, s2 = StateRef("s0", 0), StateRef("s1", 1), StateRef("s2", 0)
up = StreamingAuditMonitor(p, s0)
down = StreamingAuditMonitor(p, s1)
up.step(make_witness(p, s0, s1, witness_id="up"),
        global_evaluator_sample=1, step_cost=3)
down.step(make_witness(p, s1, s2, witness_id="down"),
          global_evaluator_sample=0, step_cost=7)
print(down.get_receipt()["status"])       # OBSTRUCTION_DETECTED
print(up.merge(down)["status"])          # COMPOSITION_VERIFIED
print(up.get_receipt()["running_cost"])  # 3, not 10
```
