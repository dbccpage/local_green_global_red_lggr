# Integration plan for the RSI monographs

This plan extends the current checkout, not the interrupted October 21 draft. The baseline inventory binds the exact sources reviewed. No existing PDF, release archive or axiom report is replaced by this research packet.

## 1. Repair the conceptual foundation first

Paper 000, Sections 1, 6 and 8, should distinguish the author's world-internal rule from the hypotheses of each finite model. Replace policy-based knowledge with record-relative determination plus a separate executable evidence relation. Retain `authorized` only on the permission axis. Incorporate the self-readout and positive-introspection results from `EmbeddedLimits.lean` as counterweights to blanket self-knowledge restrictions.

Correct the finite-alphabet argument by bounding complete histories or memory configurations. Preserve the existing pigeonhole theorem exactly at its checked type. Do not infer finite total accessible information merely from finite physical dimension when unlimited repetitions, precision, duration or expanding memory have not been bounded.

Paper 001's first section should reference the actual current companion. Its pointer to a v1.4 proof estate is not resolved by the present paper-000 files. Either restore that edition from independently verified source custody or explicitly identify it as a separate historical artifact. A directory title or remembered test count is not custody.

Acceptance condition: every claimed impossibility identifies a model, a task class, a resource restriction and an explicit failed witness or theorem. Every constructive result states what new resource or interaction it uses.

## 2. Make memory a proved operational object

Integrate the generic factorization and future-preservation core into the current Lean estate, with source-covered census entries. The new statements quantify over arbitrary types; the Python algorithms deliberately specialize to small finite deterministic models.

Use the contract tuple

```text
(model identity, readouts, action family, decoder, updater version,
 comparison class, error allowance, source bindings, byte budget)
```

for each memory experiment. Prove the commuting diagrams for an implemented updater before calling it future-preserving. Treat each new action or readout as a contract extension. Compute a distinguishing action word when old memory fails, then retain or reacquire the missing distinction. Keep the failure witness after repair.

Next runtime experiment: persist a small source-bound archive, close the process, load it in a new process, inject only a checked decoder table into the actual agent request, and test both conflicting updates and changed task contracts. Bind the final submitted prompt as well as the source snapshot. Use a controlled endpoint for interface tests, and label it separately from an actual model call. The prior prototype's presence in a historical receipt does not establish current live integration.

Acceptance condition: no failed residual or byte check can release context or commit an incompatible memory update through the supported path. Demonstrate actual recall after restart. Separately test whether the agent uses the supplied distinctions; successful injection alone is not a comprehension measurement.

## 3. Extend paper 001's solver to experiment comparison

Represent finite statistical experiments as nonnegative rational stochastic matrices over one declared parameter set. Solve for a stochastic simulation kernel and nonnegative absolute-value slack variables. Minimize a uniform total-variation error bound. Require stochasticity and all parameter-wise inequalities to be independently replayed against the original experiment matrices.

Return the kernel and upper bound as an independently checked result. A dual witness should certify a lower bound; matched bounds certify the exact deficiency. Reuse the existing solver's optimality, infeasibility and unboundedness checkers where applicable. Infeasibility of an incorrectly constrained encoding must not become a theorem that memory cannot exist.

Formalize bounded-loss risk transfer, carefully fixing the half-L1 convention and the direction of simulation. Only then pursue a converse comparison theorem. Keep prior-weighted deficiency separate from uniform deficiency. Preserve task-specific compression as a weaker requirement than all-task simulation.

Acceptance condition: identities, exact garblings, and an information-destroying binary experiment have source-pinned rational primal/dual certificates, with mutations rejected. Python-to-Lean refinement remains separately labeled until proved.

## 4. Add constructive observation and correction planning

The included finite query solver provides a first exact planning model: fixed worlds, non-destructive deterministic tests, rational target error, and worst-case query count. It checks its output independently and compares adaptive versus fixed panels.

Formalize its Bellman recurrence, strict-subset termination and optimality. For physical interventions, replace that model with action-dependent transitions and beliefs. Include forbidden actions, cost and known measurement disturbance before planning. Restrict reachability and state changes explicitly; a static separating family is not automatically an executable safe strategy.

Connect this to paper 001's correction-window bounds: if an independently justified trajectory enclosure reaches the observation margin before a query can complete, refinement is too late for that contract. Conversely, earlier correction can remain possible. A total implementation must return a checked plan or a precise resource refusal.

Acceptance condition: demonstrate the two-adaptive-versus-three-fixed example, a permanently unresolved pair under the supplied tests, and a separating-but-forbidden test. Keep computational query depth distinct from physical elapsed time.

## 5. Preserve statistical validity across learning

Declare the objective, environment distribution, null hypothesis, candidate-selection history, observation process, stopping rule and error allocation. Record all opened confirmations, including failed ones. Bound future adoption error through conditionally valid tests and an appropriate cumulative risk argument, rather than treating repeated use of a historical holdout as fresh evidence.

Use the primary confidence-sequence and adaptive-data-analysis results as imported theorems. The v2 Statistical Gödel Machines result is relevant, but its criterion controls non-improvement under a specified objective; application safety is another predicate. Predictable error allocation and valid conditional evidence are obligations, not consequences of having two verifier names.

Acceptance condition: retain a negative control in which an adaptively selected candidate overfits reused data, and a valid protocol with explicit filtration and stopping assumptions. Store source hashes, model assumptions and test policy together. A memory record should retain why a claim was supported and which later changes invalidate that support.

## 6. Extend intelligence claims through capability profiles

Use a profile indexed by environment family, task, observation policy, action budget, working memory, persistent memory and computational budget. Report both worst-case and distribution-specific performance when justified. Do not replace these with one supposedly assumption-free scalar.

Use the constructive part of the continual-learning literature: change permitted passes, replay, representation family or observation access and measure the resulting tradeoffs. Distinguish storage needed to represent a final predictor from workspace needed to learn it. Structured worlds can support major gains even though there is no universal guarantee over unrestricted environments.

Acceptance condition: compare fixed-evidence computation, new observations, memory enrichment and new actions as different interventions. Include tasks already determined by the input as controls. Report incomplete coverage and abstentions alongside errors.

## 7. Publication sequence

The research packet can be reviewed and replayed now. The next manuscript edition should integrate the agreed corrections and results, reconcile companion lineage, then use the canonical paper harmonization workflow to regenerate every rendered format, source-covered axiom census, manifest and archive. Existing releases stay unchanged until that coherent edition is ready. No claim of publication, deposit, new live model performance or broad impossibility is made by this plan.
