# Embedded knowledge and memory research

Jeremy H. Carroll research program, 22 October 2026.

Working rule: **The world is what it is. There is no outside or observer from nowhere.**

Read [research_note.md](research_note.md) for the mathematical synthesis and [extension_plan.md](extension_plan.md) for concrete integrations into the two RSI monographs. [sources.json](sources.json) records primary-source URLs, reading scope and limitations. [baseline_inventory.json](baseline_inventory.json) binds the actual checked-out papers that were reviewed.

This packet separates semantic determination, computational access, empirical learning and policy permission. It pairs task-relative limits with constructive observation, memory and evidence-preservation strategies. It contains no phenomenal premise or variable.

## Executable work

- [EmbeddedLimits.lean](EmbeddedLimits.lean) proves task factorization, self-readout and positive introspection, future-equivalence properties, sufficient conditions for an implemented memory updater, a scoped Boolean obstruction, and maximal sound report-only acceptance.
- [finite_limits.py](finite_limits.py) implements exact finite fiber certificates, guarded archive extension, future-memory refinement and optimal non-destructive query planning with independent checkers.
- [test_finite_limits.py](test_finite_limits.py) checks mutations, 65,536 future-equivalence comparisons, 16,384 semantic-knowledge cases and adaptive versus fixed query costs.
- [verification.json](verification.json) records actual execution; [Census.lean](Census.lean) and [axiom_report.txt](axiom_report.txt) enumerate every explicitly named theorem and its foundational dependencies.

Use Python 3.12 and Lean 4.35.0. The Python code uses only the standard library; the formal core needs only the installed Lean toolchain, with no Mathlib download.

```text
python -B verify.py --lean lean
```

If the toolchain is not on PATH, pass its executable path to `--lean`. Verification compiles in a temporary directory, checks the actual compiler version, replays the axiom queries, runs the tests and rechecks retained source hashes. Tests and proof declarations are not counts of independent scientific discoveries.

## Scope and custody

This is a research packet, not a rebuilt release or published third paper. The existing paper PDFs, archives and axiom censuses remain intact. The current checkout does not contain the earlier live projection-memory prototype; this packet does not claim that the live agent is automatically using its reference code. The next runtime integration is specified in the plan.

The finite algorithms do not prove source truth, world-model completeness, physical realizability, general learning impossibility, model comprehension or universal Python-to-Lean equivalence. The generic Lean statements preserve their exact assumptions. Imported statistical and quantum theorems remain imported, and their process or physical hypotheses must be established separately.
