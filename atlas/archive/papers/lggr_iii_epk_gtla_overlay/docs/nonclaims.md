# Scope note — LGGR III

**Date:** 2026-09-15

The package derives finite identities for binary evaluator records. Its Python
code computes the G1 path-pair bijection, the remaining factorization checks,
and quotient classes from actual finite data; caller-supplied truth flags are
not theorem evidence. It does not establish reliability for an arbitrary
agent, organization, software system, or physical model. A zero observed
defect can arise from an empty sample or constant evaluator, so task-specific
evaluator adequacy remains open (PL-025-6). Lean checks the finite integer and
quotient statements, not the real exponential kernel in full (PL-025-8). The
sheaf and contract references are comparisons of language, not theorem imports
or claimed equivalences.

The historical anchor is exactly dbccpage/19L57G1 tag
`sealed-derivation-v1`, commit `3100c4e`. At that frozen revision it records
the mechanical gate results described by that repository. It does not settle
source classification, theorem-to-Lean coverage, tied minima, the paper's
strongest terminal result, or this package's publication status.
